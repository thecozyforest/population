# 말랑문법 연구소

2022 개정 국어과 교육과정의 고등학교 선택 과목 **「화법과 언어」 [12화언01-03]**을 중심으로, 형태소·품사·문장 성분·문장 구조를 시각적으로 익히는 반응형 웹 애플리케이션입니다.

## 바로가기

- 배포 앱: https://thecozyforest.github.io/population/korean-grammar-lab/
- 소스 위치: `population/korean-grammar-lab/`

## 주요 기능

- **STEP 1 형태소 탐험실**: 자립/의존, 실질/형식의 두 분류 축과 24개 예시
- **STEP 2 품사 연구소**: 5언·9품사, 문맥에 따른 품사 판별과 27개 예시
- **STEP 3 문장 성분 분석소**: 주성분·부속 성분·독립 성분과 24개 예시
- **STEP 4 문장 구조 조립소**: 홑문장·이어진문장·안은문장과 24개 예시
- 각 단계의 **개념 지도 → 예시 탐색 → 직접 분류 → 표현 효과 → 새 예시 복습** 흐름
- 네 영역을 섞은 **12문항 종합 게임**과 영역별 결과 분석
- 오답과 같은 개념을 다른 문장으로 다시 보여 주는 **집중 복습**
- 별·연속 정답·진도·최고 점수·오답을 브라우저 `localStorage`에 저장
- 모바일·태블릿·PC 반응형 UI와 키보드 접근성 고려

## 파일 구성

```text
korean-grammar-lab/
├─ index.html   # 화면 구조와 접근성 마크업
├─ style.css    # 반응형 디자인·색상·애니메이션
├─ script.js    # 문법 데이터·상호작용·퀴즈·저장·예외 처리
└─ README.md    # 실행 및 유지 보수 안내
```

## 로컬에서 실행하기

### 가장 간단한 방법

1. 네 파일을 같은 폴더에 둡니다.
2. `index.html`을 더블클릭해 브라우저에서 엽니다.
3. 별도 설치나 빌드 과정은 없습니다.

### 로컬 서버로 실행하기

터미널 또는 PowerShell에서 프로젝트 폴더로 이동한 뒤 다음 명령을 실행합니다.

```bash
python -m http.server 5500
```

Windows에서 `python` 명령이 잡히지 않으면 다음을 사용합니다.

```bash
py -m http.server 5500
```

브라우저 주소창에서 `http://localhost:5500`을 엽니다. 종료할 때는 터미널에서 `Ctrl + C`를 누릅니다.

## 문법 데이터 수정 방법

모든 학습 예시는 `script.js`의 `STAGES` 객체에 영역별로 모여 있습니다.

```javascript
const STAGES = {
  morpheme: { /* 형태소 */ },
  pos: { /* 품사 */ },
  component: { /* 문장 성분 */ },
  structure: { /* 문장 구조 */ }
};
```

새 예시는 기존 `example()` 형식을 복사해 추가합니다. 앱 시작 시 `validateData()`가 다음을 자동 점검합니다.

- 단계별 예시가 20개 이상인지
- 예시 ID가 비어 있거나 중복되지 않는지
- 정답이 실제 선택지 안에 있는지
- 시각화 조각이 빠지지 않았는지

JavaScript 문법만 빠르게 검사하려면 Node.js가 설치된 환경에서 다음을 실행합니다.

```bash
node --check script.js
```
